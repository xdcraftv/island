# island
A simple dynamic island for windows

*This features :
- Media : Mainly for video/music control
- Focus : To set a focus timer and add to-do lists
- Prayer : Shows prayer time (will send notification when it's time to pray)
- Shelf : Can save media and multiple clipboard
- Weather : Self-explanatory
- System : Shows your computer's CPU, RAM, GPU, and Disks stats
also there are some notification notices for volume changing and Bluetooth conection

this was made with help of AI
you can download this and customize it on your own (Personal use only)
